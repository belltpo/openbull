OPENBULL - RUN LOCALLY (Windows CMD)

1) Start PostgreSQL once after a reboot.
   Open Command Prompt as Administrator, then copy and run:

net start postgresql-x64-18


2) Open a normal Command Prompt for the backend, then copy and run:

cd /d D:\openbull
call .venv\Scripts\activate.bat
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload


3) Keep the backend window open. Open a SECOND normal Command Prompt for the frontend,
   then copy and run:

cd /d D:\openbull\frontend
call ..\.venv\Scripts\activate.bat
npm run dev


4) Open the site:

http://127.0.0.1:5173/


Backend API documentation:

http://127.0.0.1:8000/docs


To stop either server, press Ctrl+C in its Command Prompt window.
