# 10. End-User Manual

## Access note

The source implements authenticated non-admin behavior but does not provide a current user-provisioning UI. If a non-admin account is provisioned by an approved future/operational process, server permissions restrict global administrative actions. This manual does not describe an unsupported signup or tenant workflow.

## Recommended first-use sequence

1. Sign in.
2. If directed, select and authenticate the configured broker.
3. Verify the global mode. Use Sandbox until the intended workflow is tested.
4. Wait for master-contract status to finish before searching symbols/options.
5. Verify Dashboard/account values and a live quote.
6. Use analytics or Strategy Builder without ordering first.
7. Review orders, trades, positions, holdings, and P&L after any sandbox action.
